# 全体リファクタリングの検証記録

検証日: 2026-10-30（JST）

## 変更した構造

- `app.js`を3,336行から430行へ縮小し、初期化・依存関係の接続・データ反映を担当する構成にした。
- 履修管理、科目探索、卒業要件表示、4年計画、互換マップ、ナビゲーション、ヘルプを機能別モジュールへ分離した。
- 大きい機能はダイアログ／卒業要件パネル／レイアウト／入力操作へ分けた。
- 保存先とDOMに依存しない履修状態遷移、通信を注入するデータリポジトリ、独立マップの純粋な座標計算を分離した。
- CSSを10ファイルの編集元と1ファイルの公開用生成物へ整理し、後から必ず同じ値で上書きされる完全重複宣言131件を除去した。
- 開発・QAの静的サーバー、Chromeセッション管理、プロファイル削除を共通化した。
- フォーマッター、静的解析、依存ロック、改行規約、CI、開発サーバー、設計文書を追加した。

## 修正した障害境界

- 試験日程の応答が未完了でも科目探索を開始できるようにした。
- 起動処理での未処理例外をログと短い再読込案内へ接続した。
- 必要な状態判定モジュールが欠けている場合、ユーザー操作時の不明瞭な例外にせず初期化時に検出する。
- 開発用サーバーは許可リストだけを配信し、フォーム送信や非公開ファイルへのアクセスを拒否する。

## CIで確認した環境差

Windows runnerの一時フォルダーには8.3形式の別名が使われる場合がある。許可したルートを実体パスへ正規化してからファイルを解決し、ルート配下のjunction/symlinkによる逸脱は拒否するよう修正した。ルートの別名は許可し、子リンク経由の非公開ファイルは拒否する回帰テストを追加した。

生成CSSが変化しないビルドはファイルを書き直さず、テストやwatcherが参照するファイルを不要に切り詰めないことも検証した。

## 維持したデータ契約

275科目のカタログ、科目ID、参考関係、卒業要件定義、既存配置、試験日程の元JSON・照合データは変更していない。元の試験日程JSONのSHA-256は検証済みの値をテストで固定している。

localStorageのキーと保存形式、未知IDの保持、部分保存失敗時の復元、復元失敗時の上書き停止を維持した。履修予定・履修済み・4年計画を統合していない。
